Local LLM inference on the RK3588 NPU

Usage: open_rknpu2_lm_infer [OPTIONS] <COMMAND>

Commands:
  run       Generate text; read the prompt from stdin when omitted
  chat      Open an interactive terminal conversation
  serve     Serve the OpenAI chat and text completion endpoints
  inspect   Inspect model metadata without opening the NPU
  tokenize  Encode text or decode token IDs without opening the NPU
  eval      Evaluate supplied token sequences and export logits for reference comparison
  ppl       Evaluate next-token perplexity on independent complete token windows
  bench     Benchmark independent pp/tg tests or a consecutive prefill+decode test (-pg)
  tune      Explicitly search missing strategies and save them for later inference
  help      Print this message or the help of the given subcommand(s)

Options:
  -m, --model <MODEL>
          Native safetensors model directory [env: RKNPU_MODEL=]
  -c, --ctx-size <CONTEXT>
          KV capacity in tokens; 0 selects the required bench capacity or model limit [default: 4096]
      --ubatch-size <CHUNK>
          Physical prefill batch size; also accepts -ub [default: 128]
  -t, --threads <THREADS>
          [default: 4]
      --npu-mask <NPU_MASK>
          [default: 7]
  -C, --cpu-mask <CPU_MASK>
          [default: 0xf0]
      --tune-cache <TUNE_CACHE>

      --no-tune
          Use built-in strategies instead of reading the tuning cache
      --attention-tile <ATTENTION_TILE>
          [default: 512]
      --vision-dtype <VISION_DTYPE>
          ViT intermediate tensor dtype; NPU matmul remains FP16 [default: fp16] [possible values: fp16, fp32]
  -h, --help
          Print help
  -V, --version
          Print version
